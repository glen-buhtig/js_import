Demonstration of _import(..) function.

This page demonstrates an alternative to the ES6 import function.

  • The initialising function should be run early
  • A call to _import(path) can be made from any <script> block
  • The path parameter can be absolute, or relative to the file it occurs in (not relative to the master HTML file)
  • Multiple attempts to load the same file are resolved, so that only 1 copy is loaded.
  • Loaded scripts are inserted in the <head> block of the main HTML file
  • Unlike the ES6 import(path), target files can be fetched by the file:// protocol

Trace is in browser console

Open the console in the developer tools menu to see the trace output.

There are 3 types of messages in the console.

  • "_import(..) at the point the _import function is called.
  • "Loaded/Failed to load/Queued" messages generated by _import(..) and channeled to handlers.
  • "Executing" messages embedded in the sub files showing when the script is run.
